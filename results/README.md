# Results

The completed five-policy, real-model router comparison is in [the September 25 run](2026-09-25-full-router-comparison/RESULT.md). It includes 16 calibration episodes, 24 evaluation cells, verified routes and KV-transfer evidence, and a recomputation script. The proposed fixed allowance increased mean first-token latency by 9.75–10.77% versus the tuned soft-locality reference in three matched blocks.

Earlier dated directories record deployment preparation, transport qualification, interrupted attempts and harness corrections. They explain how the final configuration was reached, but none should be read as an additional completed routing-policy comparison. The [methodology](../docs/methodology.md) describes the final protocol; the [reproduction guide](../docs/reproducing.md) explains what can be recomputed from the published data without renting GPUs.
